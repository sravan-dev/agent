# React Expo Calculator App

A beautiful and modern calculator mobile app built with React Native and Expo.

## Features

- Basic arithmetic operations (addition, subtraction, multiplication, division)
- Clear button (AC) to reset the calculator
- Decimal point support
- Modern, iOS-style dark theme UI
- Responsive design

## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn
- Expo CLI (install globally: `npm install -g expo-cli`)

### Installation

1. Install dependencies:
```bash
npm install
```

2. Start the Expo development server:
```bash
npm start
```

Or use the specific platform commands:
- iOS: `npm run ios`
- Android: `npm run android`
- Web: `npm run web`

### Using the App

Scan the QR code with the Expo Go app on your mobile device, or press `i` for iOS simulator, `a` for Android emulator, or `w` for web browser.
